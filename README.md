# Remediation Hub — Version 1.5 Organized Sessions

This upload-ready GitHub Pages PWA organizes nursing questions as Focus Review System → Session → Questions, with optional context tags.

Version 1.6 preserves ungraded/correct/incorrect/remediated states, rationale and remediation fields, session export, search, filters, image attachments, and compatibility with the v1.6 Chrome capture panel. It also preserves each session's resource and Focus Review System.

Upload every item in this folder to the root of the `Remediation-Hub` repository and replace matching files. Existing questions are preserved because this update keeps the same local storage key (`remediationHub.v1`). Do not clear Local Storage.
